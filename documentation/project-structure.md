## Data flow

```
samplePapers.js          dataAdapter.js           vizmodule.jsx
─────────────────        ──────────────────       ──────────────────────
Paper[]          ──▶     papersToScene()   ──▶    { points, edges } props
                         (positions,              (WebGL2 buffers,
                          colours,                 render loop,
                          citation edges)          camera controls)
```

## Separation of concerns

| Layer | File | Responsibility |
|---|---|---|
| Data model | `data/schema.js` | Defines the shape of a Paper object |
| Sample data | `data/samplePapers.js` | Real paper records for development/demo |
| Adapter | `data/dataAdapter.js` | Translates domain data into render-ready geometry |
| Renderer | `vizmodule.jsx` | Pure WebGL2 display — knows nothing about papers |
| Demo entry | `main.jsx` | Wires the three layers together |

## Key files

### `src/vizmodule.jsx`
Pure WebGL2 renderer. Accepts `points` (`{x,y,z,r,g,b}[]`) and `edges` (`[number,number][]`) as props. No knowledge of domain data. See [vizmodule-reference.md](./vizmodule-reference.md).

### `src/data/schema.js`
JSDoc `@typedef` for `Paper` with all fields documented. Also exports `EMPTY_PAPER` — a null-value template useful for constructing new paper objects or unit tests.

### `src/data/samplePapers.js`
Ten landmark ML/CS papers (Transformers, BERT, GPT-3, AlexNet, ResNet, GAN, RLHF, GCN, Lottery Ticket, NAS) with full metadata and cross-referenced `references_full` fields so the adapter can derive citation edges.

### `src/data/dataAdapter.js`
`papersToScene(papers)` groups papers by subfield into 3D cluster centres, adds per-paper jitter, assigns subfield colours, then derives undirected edges from `references_full`. Returns `{ points, edges }` ready for VizModule.

### `src/main.jsx`
Demo bootstrap. Calls `papersToScene(samplePapers)` inside `useMemo` (stable reference → no unnecessary WebGL reinitialisation) and passes the result to `VizModule`.
